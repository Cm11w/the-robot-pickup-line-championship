An entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun.

## The pickup line

> I ran 10,000 simulations of asking you out — you said yes in every one, so this is just a formality.

## How it works

`main.ts` writes the pickup line above to `/output/entry.txt` — one line, under 200 characters — after checking it against the competition gate (1–200 characters, not only whitespace, exactly one line).

Run it with Node 22 or later:

```sh
node main.ts
```
